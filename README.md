# Screem Weddings — 2026 Interactive Website Starter

## Included
- `index.html` — semantic, responsive website
- `styles.css` — editorial design system and mobile styles
- `script.js` — mobile navigation, portfolio filters, story lightbox, journal previews, enquiry validation/email-draft flow

## Run locally
Open `index.html` in a modern browser. For best results, use a local static server (for example VS Code Live Server).

## Before publishing
1. Replace sample Unsplash photography with licensed, approved Screem Weddings images and films.
2. Confirm the brand spelling and logo artwork. This starter uses a text-based temporary mark.
3. Replace sample portfolio and journal titles with approved work. No client stories or testimonials are claimed as real.
4. Add the studio's verified email, phone/WhatsApp, service area, privacy notice and terms.
5. Connect the enquiry form to a real backend or form provider (for example Formspree, Netlify Forms, a serverless endpoint, or your own CRM). The current form validates entries and opens a prefilled email draft; it does not send/store data automatically.
6. Configure the final domain, HTTPS, analytics/consent as appropriate, and social preview metadata.
7. Test mobile navigation, image loading, accessibility, enquiry handling and page speed on real devices.

## Design notes
Warm ivory, charcoal, muted olive and lime accent; Playfair Display + DM Sans; reduced-motion support; keyboard-accessible dialogs; responsive grid; native HTML/CSS/JS without a framework.
